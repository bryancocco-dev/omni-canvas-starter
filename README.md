# omni-canvas-starter

Public mirror of the OMNI+ Canvas starter kit (primary: omni-system-hazel.vercel.app/starters/). Exists because raw.githubusercontent.com is on the default network allowlist of sandboxed Claude Code environments, so the starter fetch works with zero configuration.

- `canvas-base.zip` — the working canvas shell + CLAUDE.md
- `canvas-base.md` — the drop-in starter CLAUDE.md
- `new.sh` — one-command scaffold

Synced from the omni-system build; do not edit here.
